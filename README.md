# Portfolio Website

My personal portfolio website showcasing my projects, skills, education, and contact information.

## Features

- Responsive design
- Modern UI
- Multiple themes (Dark, Light, Gruvbox, TokyoNight)
- Project showcase section
- Skills section
- About Me section
- Contact section
- Fast and lightweight

## Tech Stack

- HTML5
- CSS3
- JavaScript


## Getting Started

### Clone the repository

```bash
git clone https://github.com/vishal2319d/Portfolio-Vishal.git
cd Portfolio-Vishal
```

## Customization

### Themes

The website supports multiple themes through CSS variables.

Available themes:

- Dark
- Light
- Gruvbox
- TokyoNight

### Fonts

Custom fonts can be placed inside:

```text
assets/fonts/
```

and imported using `@font-face`.
